## JSON envelope

Every command emits one JSON envelope on stdout when --json is set. Errors are always structured, even without --json. next_actions is always present on success and recoverable failure; fix carries the single most actionable next step (with file:line when known).

- stdout: JSON envelope (--json) or clean human output; never mixed with logs
- stderr: progress and log lines

| Field | Meaning |
|---|---|
| `error` | null, or &#123;stage, code, message, fix, command, exit_code&#125; |
| `next_actions` | array of strings, always present on success and recoverable failure |
| `ok` | bool - true on success |
| `result` | command-specific payload, null on error |

Success example:

```json
{
  "ok": true,
  "result": { "dir": "./weather", "files_written": ["cmd/weather/main.go"], "files_skipped": [] },
  "error": null,
  "next_actions": ["cd ./weather", "mcpgen check ./weather --json"]
}
```

Failure example (always structured, even without `--json`):

```json
{
  "ok": false,
  "result": null,
  "error": {
    "stage": "test",
    "code": "TESTS_FAILED",
    "message": "1 of 3 tests failed",
    "fix": "first failure: TestGreet (greet_test.go:30); run 'go test -race ./...' in ./weather",
    "command": "go test -race ./...",
    "exit_code": 1
  },
  "next_actions": ["fix the failing test, then re-run mcpgen check ./weather --json"]
}
```

## Exit codes

Stable and safe to branch on. The constants below are parsed from `internal/cli/exit.go`.

| Code | Constant | Meaning |
|---|---|---|
| 0 | `ExitOK` | Success |
| 1 | `ExitFailure` | General failure (build/test/conformance failed) |
| 2 | `ExitUsage` | Usage error (bad flags/args, unknown config version) |
| 3 | `ExitExists` | Target directory exists and not --force / project not mcpgen-generated |
| 4 | `ExitPermission` | Permission denied (filesystem, port) |
| 5 | `ExitConflict` | Conflict (name already registered in project, markers missing) |
| 6 | `ExitPrerequisite` | Prerequisite missing (go toolchain, node/npx for conformance) |

## Self-discovery

`mcpgen schema` prints the full machine-readable contract (this envelope, all commands and flags, exit codes, and the `mcpgen.json` JSON Schema) as one JSON document on stdout. `mcpgen mcp` exposes the same operations as MCP tools (`mcpgen_new`, `mcpgen_add`, `mcpgen_check`, `mcpgen_schema`) over stdio for hosts without shell access.
