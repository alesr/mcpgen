# mcpgen docs

Documentation site for [mcpgen](https://github.com/alesr/mcpgen), built with
[Astro Starlight](https://starlight.astro.build/). Deployed to GitHub Pages at
<https://stdout.alesr.me/mcpgen/> on every push to `main`.

## Commands

```sh
make docs-dev    # from the repo root: npm ci + astro dev
make docs-build  # from the repo root: npm ci + astro build (includes link validation)
make docs-gen    # from the repo root: regenerate reference pages under
                 # src/content/docs/reference/generated/ from the Go sources
```

Or directly in this directory:

```sh
npm ci
npm run dev     # local dev server
npm run build   # production build into dist/ (fails on broken internal links)
```

## Layout

- `src/content/docs/` — all pages. Reference pages under
  `reference/generated/` are generated by `../../tools/docgen` — do not edit
  them by hand; run `make docs-gen` from the repo root instead.
- `src/content.config.ts` — Starlight content collection schema.
- `public/` — static assets (favicon, llms.txt).
- `astro.config.mjs` — site config: `site`/`base` point at the GitHub Pages
  project URL (`https://stdout.alesr.me/mcpgen/`, base `/mcpgen`).
